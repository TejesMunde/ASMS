ASMS v2.0 — Integration Repair Package
Integration pass completed: 2026-08-11

SINGLE ENTRY POINT — run this and nothing else:

    sudo ./assignment-admin

It detects whether it is running from this source tree or from an installed
ASMS, and shows the appropriate menu. From source it offers installation and
the tests, then hands over to the installed copy automatically.

    sudo ./assignment-admin --install    install, then open the menu
    sudo ./assignment-admin --check      dry run; report changes, make none
    ./assignment-admin --test            offline self-tests (no root)
    sudo assignment-admin --verify       server verification; exits 0 or 1
